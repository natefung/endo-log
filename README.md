# Endo Log (Phase 1)

Private endometriosis log for iPhone. Everything is stored on the phone only.

## 1. Put it on GitHub Pages
1. On github.com create a new repository named `endo-log` (Public; only code is stored there, never her data).
2. In the repo click **Add file → Upload files**, drag in everything from this folder (including the `icons` folder), and **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment* pick **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After a minute the app is live at `https://YOUR-USERNAME.github.io/endo-log/`.

## 2. Install on her iPhone
1. Open that link in **Safari**.
2. Tap **Share → Add to Home Screen → Add**.
3. From now on, always open it from the home-screen icon. On iPhone, the installed app keeps its own data separately from Safari tabs.

## 3. Daily reminder
In the iPhone **Reminders** app: new reminder "Log symptoms" → ⓘ → Date + Time 8:00 pm → Repeat Daily → paste the app link in **URL**. (The app's Settings screen has a Copy link button.)

## 4. Backups
Settings → **Back up now** → **Save to Files** → iCloud Drive. The app nags if the last backup is over 7 days old. **Restore backup** brings everything back on a new phone.

## Updating later
Upload the new files over the old ones in the same repo. Keep the same repo name so the link and her data stay the same.
